# 变更记录

## 2026-11-18 · 阶段一人工收货

- 收货员可以登录、创建多行采购单、按单号和到货状态筛选。
- 订单逐行显示订购、已收和待收。登记签收时，送货数和实收数独立填写。
- 点击已收数量可追溯签收单号、到货日期、确认人、送货数、实收数和备注。
- 随项目提供三份自制单据与验收标注。两批收货与补收收齐用例通过，演示单保留在两批收货终点。

## 2026-11-18 · 阶段二材料上传与异步导入

- 从任务中心可以回看已上传的采购单原件，修正解析候选值并确认建单。已确认任务直接链接到同一张采购单。
- 签收材料随订单保存和预览。扫描页和图片显示为「待 OCR」，文本页可查看提取文字。登记原件与确认收货各走对应入口。
- Worker 依靠租约续期和接管处理进程中断。任务状态、失败原因及重试入口在浏览器可见。
- Java、Python、浏览器和 V2 迁移回归通过。真实识读探针的结果见阶段二验收记录。

## 2026-11-18 · 阶段三签收解析与识别分流

- 签收任务逐页展示送货、实收候选、原文及识别区域，并可从当前订单行查看匹配理由。
- 文本 PDF 优先使用文本层。扫描件和照片使用 PaddleOCR，符合分流条件的疑难页可按配置调用豆包。
- 实收缺失、明确为 0、存在冲突和单页处理失败分别展示。签收结果查看流程保持只读。
- V3 保留历史采购导入及旧签收任务。阶段三样例及验收结果记在第三阶段计划。

## 2026-11-18 · 阶段四原图核对与收货确认

- 从订单材料列表或任务详情核对签收条目，支持按页定位 PDF 和照片、裁决候选、补录以及服务端草稿恢复。
- 按最新待收数量事务确认，重复确认返回同一收货记录。零实收可结案，并在订单材料中查回处置和确认人。
- 物料历史可打开正式收货详情，查看人工核对结果及证据。26 项 Java、11 项 Edge 回归与前端构建通过。

## 2026-11-18 · 阶段五重复识别与收货更正

- 同订单相同文件直接复用原材料和任务。同供应商同可靠单号的收货冲突可打开原记录。
- 无号收货展示同供应商、同到货日且有相同物料编码的候选，并保存核对理由。
- 收货详情可更正实收。订单状态、累计数量和待收同步更新，原确认和更正流水均可追溯。
- 历史迁移对账、34 项 Java、13 项 Edge 回归及前端构建通过。
